# 🎯 Desafío: Reto Inicial 10: Celsius a Kelvin

### 📝 Descripción del Reto
Convierte grados Celsius a Kelvin usando la fórmula K = C + 273.15. Kelvin es la escala absoluta de temperatura donde 0 K es el cero absoluto (-273.15°C). Conversión directa que practica operaciones aritméticas con decimales y el uso de constantes matemáticas.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Suma directa | K = C + 273.15 — una línea | O(1) |
| Función con validación | Verificar que C >= -273.15 antes de convertir | O(1) |
| Redondeo | Redondear resultado a 2 decimales para precisión | O(1) |

### 🌍 Dónde se usa
- **Meteorología**: estaciones de monitoreo que reportan en Kelvin
- **Ciencia**: experimentos de laboratorio que requieren escala absoluta
- **Industria**: procesos de manufacturing controlados por temperatura
- **APIs de clima**: conversión entre unidades para usuarios internacionales

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** La conversión es directa: K = C + 273.15. **Ejemplo:** 0°C → 273.15 K, 100°C → 373.15 K. **Edge cases:** cero absoluto (-273.15°C = 0 K), valores negativos.

### ⚙️ Paso 2: Implementación
Función que suma 273.15 al valor de entrada. Validar que la entrada sea numérica.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1)
**Complejidad espacial:** O(1)

```python
def celsius_a_kelvin(c):
    return c + 273.15

print(celsius_a_kelvin(0))      # 273.15
print(celsius_a_kelvin(100))    # 373.15
print(celsius_a_kelvin(-273.15)) # 0.0
print(celsius_a_kelvin(25))     # 298.15
```
