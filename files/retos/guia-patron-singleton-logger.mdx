# 🎯 Desafío: Patrón Singleton (Logger)

### 📝 Descripción del Reto
Implementa el patrón Singleton para un Logger: garantiza que solo exista una instancia global del logger en toda la aplicación. El logger debe: mantener un historial de mensajes, tener métodos `info()`, `warn()`, `error()`, y retornar siempre la misma instancia al crear múltiples objetos.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Clase estática con instancia | Variable estática privada + getInstance() | O(1) |
| Decorador/módulo level | Singleton a nivel de módulo (JS) | O(1) |
| Metaclass (Python) | Controlar creación de instancias vía metaclass | O(1) |

### 🌍 Dónde se usa
- **Logging**: un solo logger que escribe a archivo/stdout
- **Connection pools**: pool de conexiones compartido
- **Configuración**: config global de la aplicación
- **Cache**: cache compartido entre módulos

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** El Singleton controla la creación de instancias: si ya existe una, la retorna; si no, la crea. El Logger almacena un array de mensajes con timestamp y nivel. **Caso límite:** múltiples hilos (thread safety en Java), primer acceso vs. posteriores.

### ⚙️ Paso 2: Implementación
1. Variable estática/privada para la instancia.
2. Método `getInstance()` que retorna la instancia existente o crea una nueva.
3. Métodos `info()`, `warn()`, `error()` que agregan al historial.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1) por cada operación de logging.
**Complejidad espacial:** O(n) — n es el número de mensajes en el historial.

```python
from datetime import datetime

class Logger:
    _instancia = None
    _historial = []

    def __new__(cls):
        if cls._instancia is None:
            cls._instancia = super().__new__(cls)
            cls._historial = []
        return cls._instancia

    def _log(self, nivel, mensaje):
        timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        entry = f"[{nivel}] {mensaje}"
        self._historial.append(entry)
        print(f"{timestamp} {entry}")

    def info(self, mensaje): self._log("INFO", mensaje)
    def warn(self, mensaje): self._log("WARN", mensaje)
    def error(self, mensaje): self._log("ERROR", mensaje)
    def get_historial(self): return list(self._historial)

a = Logger()
b = Logger()
print(a is b)  # True

a.info("hola")
a.warn("cuidado")
a.error("fallo")
print(a.get_historial())  # ['[INFO] hola', '[WARN] cuidado', '[ERROR] fallo']
```

```java
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.util.ArrayList;
import java.util.List;

public class Logger {
    private static volatile Logger instancia;
    private final List<String> historial = new ArrayList<>();
    private final DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");

    private Logger() {}

    public static Logger getInstance() {
        if (instancia == null) {
            synchronized (Logger.class) {
                if (instancia == null) {
                    instancia = new Logger();
                }
            }
        }
        return instancia;
    }

    private void log(String nivel, String mensaje) {
        String timestamp = LocalDateTime.now().format(fmt);
        String entry = "[" + nivel + "] " + mensaje;
        historial.add(entry);
        System.out.println(timestamp + " " + entry);
    }

    public void info(String mensaje) { log("INFO", mensaje); }
    public void warn(String mensaje) { log("WARN", mensaje); }
    public void error(String mensaje) { log("ERROR", mensaje); }
    public List<String> getHistorial() { return List.copyOf(historial); }

    public static void main(String[] args) {
        Logger a = Logger.getInstance();
        Logger b = Logger.getInstance();
        System.out.println(a == b);  // true

        a.info("hola");
        a.warn("cuidado");
        a.error("fallo");
        System.out.println(a.getHistorial());
    }
}
```
