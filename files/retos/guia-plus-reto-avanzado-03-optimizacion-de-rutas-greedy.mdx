# 🎯 Desafío: Reto Avanzado 03: Optimización de Rutas (Greedy)

### 📝 Desafío del Reto
Implementa el algoritmo del **vecino más cercano** (nearest neighbor) para el problema del vendedor viajero (TSP). Dada una matriz de distancias entre ciudades, encuentra una ruta que:
1. Comience en la ciudad 0
2. Visite todas las ciudades exactamente una vez
3. Retorne a la ciudad inicial
4. Minimice la distancia total usando la estrategia greedy

**¿Por qué importa?** La optimización de rutas aparece en logística (Amazon, FedEx), transporte público, rutas de reparto, redes de telecomunicaciones y planificación de redes de energía.

**Habilidades que practica:** Algoritmos greedy, optimización combinatoria, grafos ponderados, heurísticas.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad Temporal | Complejidad Espacial |
|---------|-------------|---------------------|---------------------|
| Vecino más cercano | Siempre ir a la ciudad no visitada más cercana | O(n²) | O(n) |
| 2-opt | Mejorar la ruta intercambiando pares de aristas | O(n²) por iteración | O(n) |
| Fuerza bruta | Probar todas las permutaciones | O(n!) | O(n) |

### 🌍 Dónde se usa
1. **Logística**: optimizar rutas de reparto de Amazon, UPS, FedEx
2. **Transporte público**: planificar líneas de autobús y metro
3. **Telecomunicaciones**: optimizar la topología de redes de fibra óptica
4. **Mantenimiento**: planificar visitas técnicas a múltiples clientes

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** El algoritmo greedy del vecino más cercano funciona así: desde la ciudad actual, siempre ir a la ciudad no visitada más cercana. Al final, volver a la ciudad inicial. **Edge cases:** una sola ciudad, dos ciudades, ciudades con distancias iguales.

### ⚙️ Paso 2: Implementación
**Implementación:** Partir de ciudad 0, marcar visitada, iterar n-1 veces seleccionando la ciudad no visitada con menor distancia, sumar distancias, al final añadir distancia de retorno.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n²)  
**Complejidad espacial:** O(n)

```python
def ruta_greedy(distancias):
    n = len(distancias)
    visitadas = [False] * n
    ruta = [0]
    visitadas[0] = True
    distancia_total = 0
    actual = 0
    for _ in range(n - 1):
        mejor_dist = float('inf')
        mejor_ciudad = -1
        for ciudad in range(n):
            if not visitadas[ciudad] and distancias[actual][ciudad] < mejor_dist:
                mejor_dist = distancias[actual][ciudad]
                mejor_ciudad = ciudad
        ruta.append(mejor_ciudad)
        visitadas[mejor_ciudad] = True
        distancia_total += mejor_dist
        actual = mejor_ciudad
    distancia_total += distancias[actual][0]
    ruta.append(0)
    return ruta, distancia_total
```

function rutaGreedy(distancias) {
  const n = distancias.length;
  const visitadas = new Array(n).fill(false);
  const ruta = [0];
  visitadas[0] = true;
  let distanciaTotal = 0;
  let actual = 0;
  for (let i = 0; i < n - 1; i++) {
    let mejorDist = Infinity;
    let mejorCiudad = -1;
    for (let c = 0; c < n; c++) {
      if (!visitadas[c] && distancias[actual][c] < mejorDist) {
        mejorDist = distancias[actual][c];
        mejorCiudad = c;
      }
    }
    ruta.push(mejorCiudad);
    visitadas[mejorCiudad] = true;
    distanciaTotal += mejorDist;
    actual = mejorCiudad;
  }
  distanciaTotal += distancias[actual][0];
  ruta.push(0);
  return { ruta, distanciaTotal };
}
