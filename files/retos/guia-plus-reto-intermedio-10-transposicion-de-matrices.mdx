# 🎯 Desafío: Reto Intermedio 10: Transposición de Matrices

### 📝 Descripción del Reto
La transposición de una matriz convierte cada fila en columna y viceversa. Dada una matriz M de tamaño m×n, la matriz transpuesta M^T tiene tamaño n×m, donde M^T[j][i] = M[i][j].

Por ejemplo, si la entrada es `[[1,2],[3,4]]`, la salida debe ser `[[1,3],[2,4]]`.

**¿Por qué importa?** La transposición es fundamental en álgebra lineal y aparece en rotación de imágenes, pivoteo de tablas en bases de datos, procesamiento de señales y gráficos 3D.

**Habilidades que practica:** Manipulación de matrices, indexación bidimensional, comprensión de listas.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad Temporal | Complejidad Espacial |
|---------|-------------|---------------------|---------------------|
| zip(*matriz) en Python | Desempaquetar filas y reagrupar columnas | O(m×n) | O(m×n) |
| Bucles anidados | Intercambiar índices [i][j] → [j][i] | O(m×n) | O(m×n) |
| List comprehension | Crear nuevas filas desde columnas originales | O(m×n) | O(m×n) |

### 🌍 Dónde se usa
1. **Procesamiento de imágenes**: rotar una imagen 90° equivale a transponer su matriz de píxeles
2. **Pivoteo en bases de datos**: convertir filas en columnas para reportes cruzados
3. **Álgebra lineal**: multiplicación de matrices y operaciones con tensores
4. **Gráficos 3D**:变换 de coordenadas y cálculos de normales

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** La transposición convierte cada fila en columna. Dada M[i][j], la matriz transpuesta tiene M^T[j][i] = M[i][j]. **Edge cases:** matriz vacía (devolver []), matriz 1×1 (devolver igual), matriz de una sola fila (convertir a columna).

### ⚙️ Paso 2: Implementación
**Implementación:** En Python: `zip(*matriz)` o list comprehension `[list(f) for f in zip(*m)]`. En otros lenguajes, dos bucles anidados intercambiando índices.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(m×n)  
**Complejidad espacial:** O(m×n)

def transponer(m):

```javascript
function transponer(matriz) {
  if (matriz.length === 0) return [];
  const filas = matriz.length;
  const cols = matriz[0].length;
  const resultado = [];
  for (let j = 0; j < cols; j++) {
    const columna = [];
    for (let i = 0; i < filas; i++) {
      columna.push(matriz[i][j]);
    }
    resultado.push(columna);
  }
  return resultado;
}
```

```java
public class Transposicion {
    public static int[][] transponer(int[][] m) {
        if (m.length == 0) return new int[0][];
        int filas = m.length, cols = m[0].length;
        int[][] resultado = new int[cols][filas];
        for (int i = 0; i < filas; i++) {
            for (int j = 0; j < cols; j++) {
                resultado[j][i] = m[i][j];
            }
        }
        return resultado;
    }
}
```

    }
    resultado.push(columna);
  }
  return resultado;
}
