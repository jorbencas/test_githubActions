# 🎯 Desafío: Reto Inicial 11: Área de Triángulo

### 📝 Descripción del Reto
Calcula el área de un triángulo dados su base y altura usando la fórmula (base × altura) / 2. Ejercicio que introduce la traducción de fórmulas matemáticas a código y la validación de parámetros numéricos positivos.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Fórmula directa | (base × altura) / 2 | O(1) |
| Con validación | Verificar base > 0 y altura > 0 antes de calcular | O(1) |
| Fórmula de Herón | Usando los tres lados (requiere más cálculos) | O(1) |

### 🌍 Dónde se usa
- **Construcción**: cálculo de materiales para techos y superficies triangulares
- **Gráficos por computadora**: rasterización de triángulos en motores 3D
- **Cartografía**: cálculo de áreas en mapas y terrenos
- **Ingeniería civil**: diseño de estructuras y cálculo de cargas

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** El área se calcula como base × altura / 2. **Ejemplo:** base=3, altura=4 → 3×4/2 = 6. **Edge cases:** base o altura cero (área 0), valores negativos (no válidos).

### ⚙️ Paso 2: Implementación
Función que recibe base y altura, valida que sean positivas, aplica la fórmula y devuelve el resultado.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1)
**Complejidad espacial:** O(1)

```python
def area_triangulo(base, altura):
    return (base * altura) / 2

print(area_triangulo(3, 4))   # 6.0
print(area_triangulo(5, 5))   # 12.5
print(area_triangulo(0, 5))   # 0.0
print(area_triangulo(10, 2))  # 10.0
```

```javascript

}

```
