# 🎯 Desafío: Reto Avanzado 05: AsyncIO para Scrapers

### 📝 Descripción del Reto
Implementa un scraper web asíncrono que:
1. Reciba una lista de URLs
2. Descargue todas las páginas de forma concurrente (no secuencial)
3. Extraiga información específica de cada página (título, enlaces, etc.)
4. Devuelva los resultados como lista de objetos procesados

**¿Por qué importa?** Los scrapers asíncronos son esenciales para monitoreo de precios (Amazon), agregación de noticias, SEO analysis, y recolección de datos para machine learning. Descargar 1000 páginas secuencialmente puede tardar horas; de forma asíncrona, minutos.

**Habilidades que practica:** Programación asíncrona, async/await, concurrencia I/O-bound, manejo de errores en red.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad Temporal | Complejidad Espacial |
|---------|-------------|---------------------|---------------------|
| asyncio.gather | Ejecutar todas las peticiones en paralelo | O(n × tiempo_red) | O(n) |
| Secuencial | Descargar una por una (lento) | O(n × tiempo_red) | O(1) |
| Semáforo | Limitar concurrencia a K peticiones simultáneas | O(n × tiempo_red / K) | O(K) |

### 🌍 Dónde se usa
1. **Monitoreo de precios**: scraping de Amazon, eBay para alertas de ofertas
2. **Agregación de noticias**: recolectar artículos de múltiples fuentes
3. **SEO**: analizar posiciones de búsqueda en tiempo real
4. **Ciencia de datos**: recolectar datasets de redes sociales o APIs públicas

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Usar async/await para lanzar múltiples peticiones HTTP concurrentemente. asyncio.gather ejecuta todas las corrutinas en paralelo y espera a que terminen todas. **Edge cases:** URL inválida (error de red), timeout, respuesta no-200, contenido no-HTML.

### ⚙️ Paso 2: Implementación
**Implementación:** Definir función async de descarga, usar gather para ejecutar todas las URLs, manejar errores con try/except en cada petición individual.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n) en paralelo (depende de red)  
**Complejidad espacial:** O(n)

```python
import asyncio
import aiohttp

async def descargar_pagina(session, url):
    try:
        async with session.get(url, timeout=aiohttp.ClientTimeout(total=10)) as resp:
            html = await resp.text()
            titulo = html.split('<title>')[1].split('</title>')[0] if '<title>' in html else ''
            return {"url": url, "titulo": titulo, "status": resp.status}
    except Exception as e:
        return {"url": url, "error": str(e)}

async def scraper(urls):
    async with aiohttp.ClientSession() as session:
        tareas = [descargar_pagina(session, url) for url in urls]
        return await asyncio.gather(*tareas)
```

```javascript
async function scraper(urls) {
  async function descargar(url) {
    try {
      const resp = await fetch(url);
      const html = await resp.text();
      const match = html.match(/<title>(.*?)<\/title>/);
      return { url, titulo: match ? match[1] : '', status: resp.status };
    } catch (e) {
      return { url, error: e.message };
    }
  }
  return Promise.all(urls.map(descargar));
}
```

```java
import java.net.http.*;
import java.util.concurrent.*;
import java.util.*;
import java.util.regex.*;

public class ScraperAsync {
    public static List<Map<String, Object>> scraper(List<String> urls) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        ExecutorService executor = Executors.newFixedThreadPool(urls.size());
        List<Future<Map<String, Object>>> futures = new ArrayList<>();
        for (String url : urls) {
            futures.add(executor.submit(() -> {
                Map<String, Object> result = new HashMap<>();
                result.put("url", url);
                try {
                    HttpRequest req = HttpRequest.newBuilder().uri(URI.create(url)).build();
                    HttpResponse<String> resp = client.send(req, HttpResponse.BodyHandlers.ofString());
                    result.put("status", resp.statusCode());
                    Matcher m = Pattern.compile("<title>(.*?)</title>").matcher(resp.body());
                    result.put("titulo", m.find() ? m.group(1) : "");
                } catch (Exception e) {
                    result.put("error", e.getMessage());
                }
                return result;
            }));
        }
        List<Map<String, Object>> resultados = new ArrayList<>();
        for (Future<Map<String, Object>> f : futures) {
            resultados.add(f.get());
        }
        executor.shutdown();
        return resultados;
    }
}
```
