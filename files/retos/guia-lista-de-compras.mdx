# 🎯 Desafío: Lista de Compras

### 📝 Descripción del Reto
Implementa un gestor de lista de compras con operaciones: agregar item, eliminar item, mostrar la lista completa y buscar un item. Ejercicio que practica arrays, métodos de colección y operaciones CRUD básicas.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Array + métodos | push, splice, filter, includes | O(n) por operación |
| Clase con estado | Objeto que encapsula la lista y sus operaciones | O(n) por operación |
| Set | Usar Set para evitar duplicados | O(1) búsqueda |

### 🌍 Dónde se usa
- **Apps móviles**: listas de tareas, compras, pendientes
- **E-commerce**: carritos de compra con add/remove/update
- **Gestión de inventario**: seguimiento de productos
- **Planificación**: listas de tareas y seguimiento de progreso

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Mantener un array/lista de items. Implementar funciones para agregar (append), eliminar (remove), mostrar (list) y buscar (in). **Edge cases:** eliminar item que no existe, buscar en lista vacía.

### ⚙️ Paso 2: Implementación
Usar métodos nativos del array: push para agregar, splice/filter para eliminar, includes para buscar.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n) por operación de eliminación/búsqueda
**Complejidad espacial:** O(n)

```python
class ListaCompras:
    def __init__(self):
        self.items = []
    
    def agregar(self, item):
        self.items.append(item)
    
    def eliminar(self, item):
        if item in self.items:
            self.items.remove(item)
    
    def mostrar(self):
        return self.items
    
    def buscar(self, item):
        return item in self.items

lista = ListaCompras()
lista.agregar('leche')
lista.agregar('pan')
print(lista.mostrar())       # ['leche', 'pan']
lista.eliminar('leche')
print(lista.mostrar())       # ['pan']
print(lista.buscar('pan'))   # True
print(lista.buscar('leche')) # False
```

```javascript
class ListaCompras {
  constructor() { this.items = []; }
  agregar(item) { this.items.push(item); }
  eliminar(item) { this.items = this.items.filter(i => i !== item); }
  mostrar() { return this.items; }
  buscar(item) { return this.items.includes(item); }
}

const lista = new ListaCompras();
lista.agregar('leche');
lista.agregar('pan');
console.log(lista.mostrar());       // ['leche', 'pan']
lista.eliminar('leche');
console.log(lista.mostrar());       // ['pan']
console.log(lista.buscar('pan'));   // true
console.log(lista.buscar('leche')); // false
```

import java.util.ArrayList;

public class ListaCompras {
    private ArrayList<String> items = new ArrayList<>();
    
    public void agregar(String item) { items.add(item); }
    public void eliminar(String item) { items.remove(item); }
    public ArrayList<String> mostrar() { return items; }
    public boolean buscar(String item) { return items.contains(item); }
    
    public static void main(String[] args) {
        ListaCompras lista = new ListaCompras();
        lista.agregar("leche");
        lista.agregar("pan");
        System.out.println(lista.mostrar());       // [leche, pan]
        lista.eliminar("leche");
        System.out.println(lista.mostrar());       // [pan]
        System.out.println(lista.buscar("pan"));   // true
        System.out.println(lista.buscar("leche")); // false
    }
}
