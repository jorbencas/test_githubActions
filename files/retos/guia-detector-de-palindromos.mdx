# 🎯 Desafío: Detector de Palíndromos

### 📝 Descripción del Reto
Comprueba si una palabra o frase es un palíndromo: que se lee igual de izquierda a derecha que de derecha a izquierda, ignorando espacios, signos de puntuación y diferencias entre mayúsculas y minúsculas. Ejemplos: "Ana" → true, "A man, a plan, a canal: Panama" → true, "hola" → false.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Inversión de cadena | Normalizar y comparar con su inversa | O(n) tiempo, O(n) espacio |
| Two pointers | Comparar desde ambos extremos hacia el centro | O(n) tiempo, O(1) espacio |
| Recursivo | Comparar primer y último, recursión con subcadena | O(n) tiempo, O(n) pila |

### 🌍 Dónde se usa
- **Bioinformática**: secuencias palindrómicas en ADN son relevantes en genética
- **Validación de datos**: verificar simetría en códigos postales o identificadores
- **Compresión de datos**: algoritmos que explotan simetría en secuencias
- **Análisis literario**: detectar figuras retóricas palindrómicas en textos

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Un palíndromo es simétrico. Primero normalizar: convertir a minúsculas y eliminar no-alfanuméricos. Luego comparar con su inversa. **Ejemplo:** "A man, a plan, a canal: Panama" → "amanaplanacanalpanama" → reverso = "amanaplanacanalpanama" → true.

### ⚙️ Paso 2: Implementación
1) Convertir a minúsculas. 2) Eliminar no-alfanuméricos con regex. 3) Comparar con inversa.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n)
**Complejidad espacial:** O(n)

```python
import re

def es_palindromo(s):
    limpio = re.sub(r'[^a-z0-9]', '', s.lower())
    return limpio == limpio[::-1]

print(es_palindromo('Ana'))          # True
print(es_palindromo('hola'))         # False
print(es_palindromo('A man a plan a canal Panama'))  # True
print(es_palindromo(''))             # True
print(es_palindromo('a1a'))          # True
```

```javascript
function esPalindromo(s) {
  const limpio = s.toLowerCase().replace(/[^a-z0-9]/g, '');
  return limpio === limpio.split('').reverse().join('');
}
console.log(esPalindromo('Ana'));  // true
console.log(esPalindromo('hola')); // false
console.log(esPalindromo('A man a plan a canal Panama')); // true
console.log(esPalindromo(''));     // true
console.log(esPalindromo('a1a'));  // true
```

```java
public class Palindromo {
    public static boolean esPalindromo(String s) {
        String l = s.toLowerCase().replaceAll("[^a-z0-9]", "");
        return l.equals(new StringBuilder(l).reverse().toString());
    }
    public static void main(String[] args) {
        System.out.println(esPalindromo("Ana"));  // true
        System.out.println(esPalindromo("hola")); // false
        System.out.println(esPalindromo("A man a plan a canal Panama")); // true
        System.out.println(esPalindromo(""));     // true
        System.out.println(esPalindromo("a1a"));  // true
    }
}
```
