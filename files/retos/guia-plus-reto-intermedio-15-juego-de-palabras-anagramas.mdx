# 🎯 Desafío: Reto Intermedio 15: Juego de Palabras (Anagramas)

### 📝 Descripción del Reto
Dos palabras son anagramas si tienen exactamente los mismos caracteres con las mismas frecuencias. Por ejemplo, "listen" y "silent" contienen las mismas letras: l, i, s, t, e, n.

Debes implementar una función que reciba dos cadenas y devuelva `true` si son anagramas, `false` en caso contrario. Se debe ignorar mayúsculas/minúsculas.

**¿Por qué importa?** Los anagramas aparecen en juegos de palabras, correctores ortográficos, criptografía (ataques por frecuencia), y en algoritmos de agrupamiento de palabras (clustering).

**Habilidades que practica:** Conteo de frecuencias, uso de hashmaps/diccionarios, ordenamiento, normalización de strings.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad Temporal | Complejidad Espacial |
|---------|-------------|---------------------|---------------------|
| Ordenar y comparar | sorted(s1) == sorted(s2) | O(n log n) | O(n) |
| Mapa de frecuencias | Incrementar para s1, decrementar para s2, verificar ceros | O(n) | O(1) si alfabeto fijo |
| Array de conteo | Vector de 26 posiciones para cada letra | O(n) | O(1) |

### 🌍 Dónde se usa
1. **Juegos de palabras**: detectar anagramas en Crucigramas, Scrabble, juegos de letras
2. **Criptografía**: análisis de frecuencia para romper cifrados por sustitución
3. **Correctores ortográficos**: sugerir palabras relacionadas con las mismas letras
4. **Clustering de texto**: agrupar documentos con vocabulario similar

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Dos palabras son anagramas si tienen los mismos caracteres con las mismas frecuencias. Primero normalizar (minúsculas), luego comparar frecuencias. **Edge cases:** cadenas vacías (son anagramas), diferente longitud (false), mayúsculas (normalizar), caracteres especiales.

### ⚙️ Paso 2: Implementación
**Implementación:** Dos enfoques: 1) Ordenar las cadenas y comparar: `sorted(s1) == sorted(s2)`. 2) Contar frecuencias con un diccionario/hashmap: incrementar para s1, decrementar para s2, verificar que todos sean 0.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n) con mapa de frecuencias, O(n log n) ordenando  
**Complejidad espacial:** O(1) con array de 26 letras, O(n) con hashmap

```javascript
function sonAnagramas(a, b) {
  const normalizar = s => s.toLowerCase().split('').sort().join('');
  return normalizar(a) === normalizar(b);
}
```

```java
import java.util.*;

public class Anagramas {
    public static boolean sonAnagramas(String a, String b) {
        char[] ca = a.toLowerCase().toCharArray();
        char[] cb = b.toLowerCase().toCharArray();
        Arrays.sort(ca);
        Arrays.sort(cb);
        return Arrays.equals(ca, cb);
    }
}
```

```typescript
function sonAnagramas(a: string, b: string): boolean {
  const normalizar = (s: string) => s.toLowerCase().split('').sort().join('');
  return normalizar(a) === normalizar(b);
}
```
