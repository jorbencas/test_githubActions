# 🎯 Desafío: Máximo de Tres Números

### 📝 Descripción del Reto
Dado un array de exactamente tres números, encuentra el valor máximo. Ejercicio que practica comparaciones condicionales y el uso de funciones de utilidad como `max()` o equivalentes.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Función max | `max(arr)` — directo y legible | O(1) |
| Comparaciones encadenadas | if/else comparando a>b, a>c, b>c | O(1) |
| Ordenamiento | `sorted(arr)[-1]` — ordena y toma el último | O(1) (3 elementos) |

### 🌍 Dónde se usa
- **Sistemas de puntuación**: encontrar la mejor calificación
- **Juegos**: determinar ganador entre tres jugadores
- **Análisis de datos**: encontrar valor máximo en conjunto pequeño
- **Algoritmos**: paso intermedio en problemas de optimización

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** De tres números, el mayor es aquel que no es menor que ninguno de los otros dos. **Ejemplo:** [3, 7, 2] → 7 es mayor que 3 y que 2 → máximo = 7. **Edge cases:** todos iguales, negativos, ceros.

### ⚙️ Paso 2: Implementación
Usar función `max()` nativa del lenguaje. Alternativamente, comparaciones manuales.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1)
**Complejidad espacial:** O(1)

```python
def maximo_de_tres(arr):
    return max(arr)

print(maximo_de_tres([3, 7, 2]))    # 7
print(maximo_de_tres([10, 5, 10]))  # 10
print(maximo_de_tres([-1, -5, -2])) # -1
print(maximo_de_tres([0, 0, 0]))    # 0
```

```javascript
function maximoDeTres(arr) {
  return Math.max(...arr);
}
console.log(maximoDeTres([3, 7, 2]));    // 7
console.log(maximoDeTres([10, 5, 10]));  // 10
console.log(maximoDeTres([-1, -5, -2])); // -1
console.log(maximoDeTres([0, 0, 0]));    // 0
```

```java
public class MaximoDeTres {
    public static int maximoDeTres(int[] arr) {
        return Math.max(arr[0], Math.max(arr[1], arr[2]));
    }
    public static void main(String[] args) {
        System.out.println(maximoDeTres(new int[]{3, 7, 2}));    // 7
        System.out.println(maximoDeTres(new int[]{10, 5, 10}));  // 10
        System.out.println(maximoDeTres(new int[]{-1, -5, -2})); // -1
        System.out.println(maximoDeTres(new int[]{0, 0, 0}));    // 0
    }
}
```
