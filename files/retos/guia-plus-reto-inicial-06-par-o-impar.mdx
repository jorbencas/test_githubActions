# 🎯 Desafío: Reto Inicial 06: Par o Impar

### 📝 Descripción del Reto
Determina si un número entero es par o impar. Un número par es divisible exactamente entre 2 (resto 0), mientras que un impar deja resto 1. Este ejercicio introduce el operador módulo (%), esencial en juegos (turnos alternados), validación de datos y procesamiento cíclico.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Operador módulo | `n % 2 == 0` — directo y legible | O(1) |
| Bitwise AND | `n & 1 == 0` — más eficiente a nivel de hardware | O(1) |
| División entera | Verificar si `n / 2 * 2 == n` | O(1) |

### 🌍 Dónde se usa
- **Juegos**: alternar turnos entre jugadores (par = jugador 1, impar = jugador 2)
- **Interfaces gráficas**: generar patrones de tablero tipo ajedrez (checkerboard)
- **Procesamiento de datos**: filtrar elementos pares/impares de una lista
- **Validación de documentos**: números de identificación que siguen reglas de paridad

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** La paridad se determina con el operador módulo: `n % 2` devuelve el resto de dividir entre 2. Si el resto es 0 → par; si es 1 → impar. **Ejemplo:** 4 ÷ 2 = 2 resto 0 → Par. 7 ÷ 2 = 3 resto 1 → Impar. **Edge cases:** número 0 (es par), negativos (funciona igual), números grandes (solo una operación).

### ⚙️ Paso 2: Implementación
Usamos el operador módulo `%` en una línea. Alternativa bitwise: `n & 1` revisa el último bit del binario (0 = par, 1 = impar).

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1)
**Complejidad espacial:** O(1)

### 💻 Código de la Solución

<CodeTabs client:load>

```python
def par_o_impar(n):
    return 'Par' if n % 2 == 0 else 'Impar'

print(par_o_impar(4))   # Par
print(par_o_impar(7))   # Impar
print(par_o_impar(-12)) # Par
```

```javascript
function parOImpar(n) {
  return n % 2 === 0 ? 'Par' : 'Impar';
}
console.log(parOImpar(4));  // Par
console.log(parOImpar(7));  // Impar
console.log(parOImpar(-12)); // Par
```
