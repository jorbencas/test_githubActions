# 🎯 Desafío: Verificador de Edad

### 📝 Descripción del Reto
Dada una edad, clasifica en: "Menor de edad" (menor que 18), "Mayor de edad" (18 o más) o "Exactamente 18" (igual a 18). Ejercicio de lógica condicional con múltiples ramificaciones que practica la toma de decisiones en código.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| if/else if/else | Clasificación directa con tres ramas | O(1) |
| Match/switch | Usar expresión match en Python o switch en otros | O(1) |
| Diccionario de rangos | Mapear rangos a clasificaciones | O(1) |

### 🌍 Dónde se usa
- **Sitios web**: verificar edad para contenido restringido (alcohol, juegos)
- **Formularios de registro**: validar requisitos de edad para servicios
- **Sistemas de seguridad**: control de acceso según categoría de edad
- **Legislación**: aplicar leyes diferentes según tramos de edad

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Tres ramas condicionales: si edad < 18 → menor; si edad == 18 → exactamente 18; si edad > 18 → mayor. **Edge cases:** edad 0 (menor), edad negativa (inválido), edad muy alta.

### ⚙️ Paso 2: Implementación
Usar if/else if/else para las tres condiciones. Validar que la edad sea positiva.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1)
**Complejidad espacial:** O(1)

```python
def verificar_edad(edad):
    if edad < 18:
        return 'Menor de edad'
    elif edad == 18:
        return 'Exactamente 18'
    else:
        return 'Mayor de edad'

print(verificar_edad(15))  # Menor de edad
print(verificar_edad(18))  # Exactamente 18
print(verificar_edad(25))  # Mayor de edad
```

```javascript

}

```
