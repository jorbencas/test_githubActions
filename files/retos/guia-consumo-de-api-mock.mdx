# 🎯 Desafío: Consumo de API Mock

### 📝 Descripción del Reto
Simula el consumo de una API REST de usuarios usando datos mock. Implementa operaciones GET (obtener todos), GET por ID, y filtrado por campos. Practica manejo de objetos JSON, estructuras de datos anidadas y diseño de interfaces de API.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Array de objetos | Buscar con filter/find en array mock | O(n) por consulta |
| Diccionario por ID | Indexar por ID para acceso O(1) | O(1) por ID, O(n) por filtro |
| Simulación async | Usar Promises/async para simular latencia | O(n) |

### 🌍 Dónde se usa
- **Frontend**: consumo de APIs durante desarrollo antes de tener backend
- **Testing**: mockear respuestas de API en pruebas unitarias
- **Prototipado**: crear MVP sin backend real
- **Demostraciones**: mostrar funcionalidad con datos ficticios

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Crear un array de objetos mock con campos id, nombre, email, ciudad. Implementar métodos: getAll(), getById(id), filterBy(field, value). **Edge cases:** ID no existe (null), filtro sin resultados (array vacío).

### ⚙️ Paso 2: Implementación
Crear clase/conjunto de funciones que encapsulen el array mock. Usar find, filter para consultas.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n) por filtro, O(1) por ID (si indexado)
**Complejidad espacial:** O(n)

```python
class APIMock:
    def __init__(self):
        self.usuarios = [
            {"id": 1, "nombre": "Ana", "ciudad": "Madrid"},
            {"id": 2, "nombre": "Luis", "ciudad": "Barcelona"},
            {"id": 3, "nombre": "María", "ciudad": "Madrid"},
        ]
    
    def get_all(self):
        return self.usuarios
    
    def get_by_id(self, id):
        return next((u for u in self.usuarios if u["id"] == id), None)
    
    def filter_by(self, campo, valor):
        return [u for u in self.usuarios if u.get(campo) == valor]

api = APIMock()
print(api.get_all())
print(api.get_by_id(1))              # {'id': 1, 'nombre': 'Ana', 'ciudad': 'Madrid'}
print(api.get_by_id(99))             # None
print(api.filter_by("ciudad", "Madrid"))  # Ana, María
```

```java
import java.util.*;
import java.util.stream.*;

public class APIMock {
    private List<Map<String, Object>> usuarios = List.of(
        Map.of("id", 1, "nombre", "Ana", "ciudad", "Madrid"),
        Map.of("id", 2, "nombre", "Luis", "ciudad", "Barcelona"),
        Map.of("id", 3, "nombre", "María", "ciudad", "Madrid")
    );
    
    public List<Map<String, Object>> getAll() { return usuarios; }
    
    public Map<String, Object> getById(int id) {
        return usuarios.stream().filter(u -> (int)u.get("id") == id).findFirst().orElse(null);
    }
    
    public List<Map<String, Object>> filterBy(String campo, Object valor) {
        return usuarios.stream().filter(u -> u.get(campo).equals(valor)).collect(Collectors.toList());
    }
    
    public static void main(String[] args) {
        APIMock api = new APIMock();
        System.out.println(api.getAll());
        System.out.println(api.getById(1));
        System.out.println(api.filterBy("ciudad", "Madrid"));
    }
}
```
