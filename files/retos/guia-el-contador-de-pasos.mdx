# 🎯 Desafío: El Contador de Pasos

### 📝 Descripción del Reto
Dado un número entero `n`, calcula el mínimo número de pasos para reducirlo a 0. En cada paso puedes: (1) restar 1 si el número es impar, o (2) dividir entre 2 si es par. Implementa la solución de forma eficiente sin usar recursión excesiva.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Iterativo greedy | Si es par dividir, si es par restar, contar pasos | O(log n) |
| Recursivo | Llamada recursiva con memoización | O(log n) |
| Bitwise | Contar bits: pasos = número de bits 1 + posición del bit más alto | O(log n) |

### 🌍 Dónde se usa
- **Optimización de procesos**: minimizar operaciones en pipelines
- **Juegos**: mecánicas de reducción de recursos
- **Criptografía**: análisis de complejidad de operaciones en anillos
- **Educación**: introducción a greedy algorithms

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Es un problema greedy. Si `n` es par, dividir entre 2 siempre es mejor (reduce más rápido). Si es impar, restar 1 para hacerlo par. **Caso límite:** n=0 (0 pasos), n=1 (1 paso).

### ⚙️ Paso 2: Implementación
Iterar mientras `n > 0`: si es par, dividir entre 2; si es impar, restar 1. Contar cada operación.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(log n) — cada división reduce el número a la mitad.
**Complejidad espacial:** O(1) — solo contadores.

```python
def contar_pasos(n):
    pasos = 0
    while n > 0:
        if n % 2 == 0:
            n //= 2
        else:
            n -= 1
        pasos += 1
    return pasos

print(contar_pasos(8))   # 3
print(contar_pasos(7))   # 4
print(contar_pasos(1))   # 1
print(contar_pasos(0))   # 0
print(contar_pasos(15))  # 5
```

```javascript
function contarPasos(n) {
  let pasos = 0;
  while (n > 0) {
    if (n % 2 === 0) n = Math.floor(n / 2);
    else n -= 1;
    pasos++;
  }
  return pasos;
}
console.log(contarPasos(8));   // 3
console.log(contarPasos(7));   // 4
console.log(contarPasos(1));   // 1
console.log(contarPasos(0));   // 0
console.log(contarPasos(15));  // 5
```

        return pasos;
