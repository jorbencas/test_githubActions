# 🎯 Desafío: Reto Inicial 30: Limpieza de Texto

### 📝 Descripción del Reto
Limpia una cadena de texto eliminando caracteres no deseados: espacios extra al inicio/final, signos de puntuación, y convirtiendo a minúsculas. Transforma '  HOLA   MUNDO!  ' en 'hola mundo'. Práctica esencial para sanitización de input y preparación de datos.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| strip + lowercase | `s.strip().lower()` — solo espacios | O(n) |
| Regex | `re.sub(r'[^a-z0-9\s]', '', s.lower())` — completo | O(n) |
| Split + join | ` ' '.join(s.split())` — normalizar espacios | O(n) |

### 🌍 Dónde se usa
- **NLP / IA**: preparar texto para análisis de sentimiento y modelos
- **Bases de datos**: sanitizar datos de usuarios antes de insertar
- **Búsqueda de texto**: normalizar queries para búsqueda full-text
- **Logs**: limpiar y estandarizar mensajes de sistema

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Aplicar transformaciones: trim (eliminar espacios extremos), lower (minúsculas), eliminar puntuación con regex. **Ejemplo:** '  HOLA   MUNDO!  ' → trim → 'HOLA   MUNDO!' → lower → 'hola   mundo!' → regex → 'hola   mundo' → normalizar espacios → 'hola mundo'.

### ⚙️ Paso 2: Implementación
Usar expresiones regulares para reemplazar caracteres no deseados. En Python: `re.sub(r'[^a-z0-9\s]', '', s.lower())` seguido de normalizar espacios.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n)
**Complejidad espacial:** O(n)

```python
import re

def limpiar_texto(s):
    limpio = s.strip().lower()
    limpio = re.sub(r'[^a-z0-9\s]', '', limpio)
    return ' '.join(limpio.split())

print(limpiar_texto('  HOLA   MUNDO!  '))  # hola mundo
print(limpiar_texto('Python!!!'))           # python
print(limpiar_texto(''))                    # 
print(limpiar_texto('  a  b  c  '))        # a b c
```

```javascript
function limpiarTexto(s) {
  return s.trim().toLowerCase()
    .replace(/[^a-z0-9\s]/g, '')
    .replace(/\s+/g, ' ');
}
console.log(limpiarTexto('  HOLA   MUNDO!  ')); // hola mundo
console.log(limpiarTexto('Python!!!'));          // python
console.log(limpiarTexto(''));                   // 
console.log(limpiarTexto('  a  b  c  '));       // a b c
```

```java
public class LimpiezaDeTexto {
    public static String limpiarTexto(String s) {
        return s.trim().toLowerCase()
            .replaceAll("[^a-z0-9\\s]", "")
            .replaceAll("\\s+", " ");
    }
    public static void main(String[] args) {
        System.out.println(limpiarTexto("  HOLA   MUNDO!  ")); // hola mundo
        System.out.println(limpiarTexto("Python!!!"));          // python
        System.out.println(limpiarTexto(""));                   // 
        System.out.println(limpiarTexto("  a  b  c  "));       // a b c
    }
}
```
