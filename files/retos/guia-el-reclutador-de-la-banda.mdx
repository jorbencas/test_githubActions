# 🎯 Desafío: El Reclutador de la Banda

### 📝 Descripción del Reto
Dada una lista de músicos con sus atributos (nombre, instrumento, nivel de experiencia y disponibilidad), filtra y retorna solo aquellos que cumplan con los criterios del evento: instrumento requerido, nivel mínimo de experiencia y que estén disponibles. Ordena el resultado por experiencia (mayor primero).

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Filter + Sort | Filtrar con condiciones múltiples, luego ordenar | O(n log n) |
| Two-pass | Primera pasada filtra, segunda pasada ordena | O(n log n) |
| Divide and conquer | Separar por instrumento, luego filtrar nivel | O(n log n) |

### 🌍 Dónde se usa
- **Recruiting**: filtrar candidatos por skills y disponibilidad
- **Eventos**: seleccionar proveedores que cumplan requisitos
- **Gaming**: componer equipos según stats de personajes
- **RRHH**: matching de empleados a proyectos

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Recorrer la lista y aplicar tres filtros: instrumento igual al requerido, experiencia >= mínimo, y disponibilidad == true. Luego ordenar por experiencia descendente. **Caso límite:** lista vacía, nadie cumple criterios.

### ⚙️ Paso 2: Implementación
1. Filtrar por instrumento, nivel y disponibilidad.
2. Ordenar por experiencia descendente.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n log n) — dominada por la ordenación.
**Complejidad espacial:** O(n) — para la lista filtrada.

def reclutar(musicos, instrumento, nivel_min):
    filtrados = [m for m in musicos
                 if m["inst"] == instrumento
                 and m["exp"] >= nivel_min
                 and m["disp"]]
    return sorted(filtrados, key=lambda m: m["exp"], reverse=True)

banda = [
    {"name": "Ana", "inst": "guitarra", "exp": 5, "disp": True},
    {"name": "Luis", "inst": "bajo", "exp": 3, "disp": True},

function reclutar(musicos, instrumento, nivelMin) {
  return musicos
    .filter(m => m.inst === instrumento && m.exp >= nivelMin && m.disp)
    .sort((a, b) => b.exp - a.exp);
}

```java
import java.util.*;
import java.util.stream.*;

public class ReclutadorBanda {
    public static List<Map<String,Object>> reclutar(
            List<Map<String,Object>> musicos, String instrumento, int nivelMin) {
        return musicos.stream()
            .filter(m -> m.get("inst").equals(instrumento)
                      && (int)m.get("exp") >= nivelMin
                      && (boolean)m.get("disp"))
            .sorted((a, b) -> (int)b.get("exp") - (int)a.get("exp"))
            .collect(Collectors.toList());
    }

    public static void main(String[] args) {
        var banda = List.of(
            Map.of("name","Ana","inst","guitarra","exp",5,"disp",true),
            Map.of("name","Luis","inst","bajo","exp",3,"disp",true),
            Map.of("name","Marta","inst","guitarra","exp",2,"disp",true)
        );
        System.out.println(reclutar(banda, "guitarra", 2));
    }
}
```
