# 🎯 Desafío: Reto Inicial 19: Descuento Simple

### 📝 Descripción del Reto
Aplica un descuento porcentual a un precio y devuelve el precio final. Similar al cálculo de IVA pero restando en vez de sumar. Fórmula: precio_final = precio × (1 - descuento/100). Práctica esencial para sistemas de venta y promociones.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Fórmula directa | `precio * (1 - descuento/100)` | O(1) |
| Dos pasos | Calcular descuento y restarlo por separado | O(1) |
| Redondeo | `Math.round()` para evitar decimales | O(1) |

### 🌍 Dónde se usa
- **E-commerce**: aplicar cupones y códigos de descuento
- **Sistemas POS**: rebajas y ofertas en tiendas físicas
- **Liquidación de inventario**: calcular precios de salida
- **Marketing**: campañas promocionales con porcentajes variables

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Descuento = precio × (porcentaje / 100). Precio final = precio - descuento. **Ejemplo:** precio=100, descuento=15% → 100 - 15 = 85. **Edge cases:** descuento 0% (sin cambio), descuento 100% (gratis).

### ⚙️ Paso 2: Implementación
Una línea: `precio * (1 - descuento / 100)`. Validar que descuento esté entre 0 y 100.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1)
**Complejidad espacial:** O(1)

```python
def descuento_simple(precio, descuento):
    return round(precio * (1 - descuento / 100), 2)

print(descuento_simple(100, 15))  # 85.0
print(descuento_simple(200, 50))  # 100.0
print(descuento_simple(80, 0))    # 80.0
print(descuento_simple(50, 100))  # 0.0
```

```javascript
function descuentoSimple(precio, descuento) {
  return Math.round(precio * (1 - descuento / 100) * 100) / 100;
}

console.log(descuentoSimple(200, 50));  // 100
console.log(descuentoSimple(80, 0));    // 80

```
