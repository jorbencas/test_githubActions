# 🎯 Desafío: Reto Inicial 24: Raíz Cuadrada (Redondeada)

### 📝 Descripción del Reto
Calcula la raíz cuadrada de un número y la redondea al entero más cercano. Usa las funciones `sqrt()` de la librería matemática y `round()` para el redondeo. Ejercicio que introduce el uso de bibliotecas estándar y manejo de números de punto flotante.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| sqrt + round | `round(sqrt(n))` — directo | O(log n) |
| Aproximación Newton | Método iterativo sin librería | O(log n) |
| Potencia 0.5 | `n ** 0.5` luego round | O(log n) |

### 🌍 Dónde se usa
- **Gráficos 3D**: cálculo de distancias euclidianas entre puntos
- **Procesamiento de señales**: normalización y cálculo de magnitudes
- **Estadística**: desviación estándar y varianza
- **Física**: cinemática, órbitas, movimiento browniano

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Se usa `sqrt()` para obtener la raíz cuadrada y `round()` para redondear. **Ejemplo:** 10 → sqrt(10) ≈ 3.162 → redondeado → 3. **Edge cases:** número negativo (dominio inválido), cero (0).

### ⚙️ Paso 2: Implementación
`round(sqrt(n))`. Manejar excepción para números negativos.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(log n)
**Complejidad espacial:** O(1)

```python
import math

def raiz_cuadrada(n):
    return round(math.sqrt(n))

print(raiz_cuadrada(10))  # 3
print(raiz_cuadrada(16))  # 4
print(raiz_cuadrada(25))  # 5
print(raiz_cuadrada(2))   # 1
print(raiz_cuadrada(0))   # 0
```

```javascript
function raizCuadrada(n) {
  return Math.round(Math.sqrt(n));
}
console.log(raizCuadrada(10)); // 3

console.log(raizCuadrada(25)); // 5
console.log(raizCuadrada(2));  // 1
console.log(raizCuadrada(0));  // 0
```

}
