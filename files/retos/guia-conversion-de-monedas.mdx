# 🎯 Desafío: Conversión de Monedas

### 📝 Descripción del Reto
Implementa un convertidor de monedas: dado un monto, una moneda origen, una moneda destino y un diccionario de tasas de cambio, calcula el monto convertido. Las tasas se dan como `{"EUR_USD": 1.08, "EUR_GBP": 0.86, ...}`. Si falta una tasa directa, intenta usar una ruta indirecta (ej. EUR→USD→GBP).

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Tasa directa | Buscar la tasa exacta en el diccionario | O(1) |
| Ruta indirecta BFS | Buscar camino de conversión como grafo no dirigido | O(V + E) |
| Matriz de tasas | Construir matriz completa con Floyd-Warshall | O(n³) |

### 🌍 Dónde se usa
- **Fintech**: apps como Wise, Revolut para transferencias internacionales
- **E-commerce**: precios en múltiples monedas para tiendas globales
- **Trading**: plataformas de forex y criptomonedas
- **Contabilidad**: consolidación de estados financieros multi-moneda

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Las tasas se modelan como un grafo no dirigido donde cada moneda es un nodo y cada tasa es una arista bidireccional (EUR→USD con tasa 1.08 implica USD→EUR con tasa 1/1.08). Para buscar una conversión, usar BFS desde la moneda origen hasta la destino, multiplicando tasas en el camino. **Caso límite:** moneda origen == destino (retornar monto), sin ruta posible (retornar null).

### ⚙️ Paso 2: Implementación
1. Construir grafo de adyacencia desde las tasas.
2. BFS desde origen, acumulando el producto de tasas.
3. Al llegar al destino, multiplicar por el monto original.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(V + E) — BFS en el grafo de monedas.
**Complejidad espacial:** O(V + E) — para la lista de adyacencia.

```python
from collections import defaultdict, deque

def convertir(monto, origen, destino, tasas):
    if origen == destino:
        return float(monto)
    grafo = defaultdict(dict)
    for par, tasa in tasas.items():
        de, a = par.split("_")
        grafo[de][a] = tasa
        grafo[a][de] = 1.0 / tasa

    cola = deque([(origen, 1.0)])
    visitado = {origen}
    while cola:
        nodo, tasa_acum = cola.popleft()
        if nodo == destino:
                return round(monto * tasa_acum, 2)
            for vecino, t in grafo[nodo].items():
                if vecino not in visitado:
                    visitado.add(vecino)
                    cola.append((vecino, tasa_acum * t))
    return None

print(convertir(100, "EUR", "USD", {"EUR_USD": 1.08}))       # 108.0
print(convertir(100, "EUR", "GBP", {"EUR_USD": 1.08, "USD_GBP": 0.79}))  # 85.32
print(convertir(100, "EUR", "EUR", {}))                       # 100.0
print(convertir(100, "EUR", "JPY", {}))                       # None
```

```javascript
function convertir(monto, origen, destino, tasas) {
  if (origen === destino) return monto;
  const grafo = {};
  for (const [par, tasa] of Object.entries(tasas)) {
    const [de, a] = par.split("_");
    if (!grafo[de]) grafo[de] = {};
    if (!grafo[a]) grafo[a] = {};
    grafo[de][a] = tasa;
    grafo[a][de] = 1 / tasa;
  }
  const cola = [[origen, 1]];
  const visitado = new Set([origen]);
  while (cola.length) {
    const [nodo, tasaAcum] = cola.shift();
    if (nodo === destino) return Math.round(monto * tasaAcum * 100) / 100;
    for (const [vecino, t] of Object.entries(grafo[nodo] || {})) {
      if (!visitado.has(vecino)) {
        visitado.add(vecino);
        cola.push([vecino, tasaAcum * t]);
      }
    }
  }
  return null;
}
```

```java
import java.util.*;

public class ConversionMonedas {
    public static Double convertir(double monto, String origen, String destino, Map<String,Double> tasas) {
        if (origen.equals(destino)) return monto;
        Map<String, Map<String,Double>> grafo = new HashMap<>();
        for (var entry : tasas.entrySet()) {
            String[] partes = entry.getKey().split("_");
            grafo.computeIfAbsent(partes[0], k -> new HashMap<>()).put(partes[1], entry.getValue());
            grafo.computeIfAbsent(partes[1], k -> new HashMap<>()).put(partes[0], 1 / entry.getValue());
        }
        Queue<Object[]> cola = new LinkedList<>();
        cola.add(new Object[]{origen, 1.0});
        Set<String> visitado = new HashSet<>(Set.of(origen));
        while (!cola.isEmpty()) {
            var actual = cola.poll();
            String nodo = (String) actual[0];
            double tasaAcum = (double) actual[1];
            if (nodo.equals(destino)) return Math.round(monto * tasaAcum * 100.0) / 100.0;
            for (var vecino : grafo.getOrDefault(nodo, Map.of()).entrySet()) {
                if (!visitado.contains(vecino.getKey())) {
                    visitado.add(vecino.getKey());
                    cola.add(new Object[]{vecino.getKey(), tasaAcum * vecino.getValue()});
                }
            }
        }
        return null;
    }

    public static void main(String[] args) {
        System.out.println(convertir(100, "EUR", "USD", Map.of("EUR_USD", 1.08))); // 108.0
        System.out.println(convertir(100, "EUR", "GBP", Map.of("EUR_USD", 1.08, "USD_GBP", 0.79))); // 85.32
    }
}
```

```typescript
function convertir(monto: number, origen: string, destino: string, tasas: Record<string, number>): number | null {
  if (origen === destino) return monto;
  const grafo: Record<string, Record<string, number>> = {};
  for (const [par, tasa] of Object.entries(tasas)) {
    const [de, a] = par.split("_");
    if (!grafo[de]) grafo[de] = {};
    if (!grafo[a]) grafo[a] = {};
    grafo[de][a] = tasa;
    grafo[a][de] = 1 / tasa;
  }
  const cola: [string, number][] = [[origen, 1]];
  const visitado = new Set([origen]);
  while (cola.length) {
    const [nodo, tasaAcum] = cola.shift()!;
    if (nodo === destino) return Math.round(monto * tasaAcum * 100) / 100;
    for (const [vecino, t] of Object.entries(grafo[nodo] || {})) {
      if (!visitado.has(vecino)) {
        visitado.add(vecino);
        cola.push([vecino, tasaAcum * t]);
      }
    }
  }
  return null;
}
```
