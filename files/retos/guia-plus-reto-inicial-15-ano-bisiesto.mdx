# 🎯 Desafío: Reto Inicial 15: Año Bisiesto

### 📝 Descripción del Reto
Determina si un año es bisiesto según las reglas del calendario gregoriano: un año es bisiesto si es divisible entre 4, excepto los años de siglo (divisibles entre 100) que no son bisiestos, a menos que sean divisibles entre 400. Ejercicio perfecto para practicar operadores lógicos AND, OR y precedencia.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Condición compuesta | `(y%4==0 and y%100!=0) or (y%400==0)` | O(1) |
| Negaciones encadenadas | `y%4!=0 ? false : (y%100!=0 ? true : y%400==0)` | O(1) |
| Librería estándar | `calendar.isleap(y)` en Python | O(1) |

### 🌍 Dónde se usa
- **Sistemas de calendario**: planificación de eventos y recordatorios anuales
- **Cálculo de días entre fechas**: contratos, suscripciones, intereses
- **Base de datos**: campos de tipo fecha que necesitan validación
- **Hojas de cálculo**: fórmulas deExcel/Sheets para planificación

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Un año es bisiesto si: (divisible entre 4 Y NO entre 100) O (divisible entre 400). **Ejemplo:** 2024 → sí (divisible entre 4, no entre 100). 1900 → no (divisible entre 100, no entre 400). 2000 → sí (divisible entre 400).

### ⚙️ Paso 2: Implementación
Evaluar la condición compuesta: `(año % 4 == 0 and año % 100 != 0) or (año % 400 == 0)`.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1)
**Complejidad espacial:** O(1)

### 💻 Código de la Solución

```python
def es_bisiesto(año):
    return (año % 4 == 0 and año % 100 != 0) or (año % 400 == 0)

print(es_bisiesto(2024))  # True
print(es_bisiesto(2023))  # False
print(es_bisiesto(1900))  # False
print(es_bisiesto(2000))  # True
print(es_bisiesto(2400))  # True
```

```javascript
function esBisiesto(año) {
  return (año % 4 === 0 && año % 100 !== 0) || (año % 400 === 0);
}

console.log(esBisiesto(2023)); // false
console.log(esBisiesto(1900)); // false
console.log(esBisiesto(2000)); // true
console.log(esBisiesto(2400)); // true
```
