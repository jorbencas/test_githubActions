# 🎯 Desafío: Reto Avanzado 06: Middleware de Seguridad

### 📝 Descripción del Reto
Implementa un sistema de middlewares que valide peticiones HTTP antes de que lleguen al handler principal. Los middlewares deben:
1. **Rate Limiter**: limitar peticiones por IP (máximo N por ventana de tiempo)
2. **Auth Validator**: verificar que el header `Authorization` contenga un token válido
3. **IP Blocker**: bloquear IPs en una lista negra

Los middlewares se encadenan: si alguno falla, la petición se rechaza con el error correspondiente.

**¿Por qué importa?** Express.js (Node.js), Spring Boot (Java) y Django (Python) usan middlewares para seguridad. Cada petición a tu API debe pasar por validación de autenticación, rate limiting y filtrado de IPs maliciosas.

**Habilidades que practica:** Patrón middleware/chain of responsibility, closures, manejo de estado, programación funcional.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad Temporal | Complejidad Espacial |
|---------|-------------|---------------------|---------------------|
| Cadena de funciones | Cada middleware llama al siguiente o rechaza | O(1) por middleware | O(k) k=middlewares |
| Decoradores | Anotaciones que envuelven la función | O(1) | O(1) |
| Pipeline funcional | Composición de funciones puras | O(1) | O(1) |

### 🌍 Dónde se usa
1. **APIs REST**: Express.js usa middleware para CORS, body-parser, auth
2. **Gateways**: AWS API Gateway y Kong aplican rate limiting y auth
3. **CDNs**: Cloudflare filtra tráfico malicioso con middlewares de seguridad
4. **Microservicios**: cada servicio valida tokens JWT en su pipeline

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Cada middleware es una función que recibe la petición y una función next. Si la validación pasa, llama a next(). Si falla, devuelve error. Los middlewares se componen en cadena. **Edge cases:** petición sin headers, IP vacía, rate limiter con ventana expirada.

### ⚙️ Paso 2: Implementación
**Implementación:** Función compose que encadena middlewares. Cada middleware tiene firma `(req, next) => resultado`. Rate limiter usa mapa de IPs con timestamps.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(k) donde k = número de middlewares  
**Complejidad espacial:** O(n) para rate limiter (n = IPs únicas)

```python
import time

class MiddlewareChain:
    def __init__(self):
        self.middlewares = []
    
    def use(self, middleware):
        self.middlewares.append(middleware)
    
    def execute(self, req):
        for mw in self.middlewares:
            result = mw(req)
            if result is not None:
                return result
        return {"status": "ok"}

def auth_middleware(req):
    token = req.get("headers", {}).get("Authorization")
    if not token:
        return {"status": "unauthorized"}
    return None

def ip_blocker(blocked_ips):
    def middleware(req):
        if req.get("ip") in blocked_ips:
            return {"status": "blocked"}
        return None
    return middleware

def rate_limiter(max_requests, window=60):
    requests = {}
    def middleware(req):
        ip = req.get("ip")
        now = time.time()
        if ip not in requests:
            requests[ip] = []
        requests[ip] = [t for t in requests[ip] if now - t < window]
        if len(requests[ip]) >= max_requests:
            return {"status": "rate limited"}
        requests[ip].append(now)
        return None
    return middleware
```

```java
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

public class MiddlewareChain {
    private List<Middleware> middlewares = new ArrayList<>();

    public void use(Middleware mw) {
        middlewares.add(mw);
    }

    public Map<String, Object> execute(Map<String, Object> req) {
        for (Middleware mw : middlewares) {
            Map<String, Object> result = mw.process(req);
            if (result != null) return result;
        }
        return Map.of("status", "ok");
    }

    public interface Middleware {
        Map<String, Object> process(Map<String, Object> req);
    }

    public static Middleware authMiddleware() {
        return req -> {
            Map<String, String> headers = (Map<String, String>) req.get("headers");
            if (headers == null || !headers.containsKey("Authorization"))
                return Map.of("status", "unauthorized");
            return null;
        };
    }

    public static Middleware ipBlocker(Set<String> blocked) {
        return req -> {
            if (blocked.contains(req.get("ip")))
                return Map.of("status", "blocked");
            return null;
        };
    }

    public static Middleware rateLimiter(int maxRequests) {
        ConcurrentHashMap<String, List<Long>> requests = new ConcurrentHashMap<>();
        return req -> {
            String ip = (String) req.get("ip");
            long now = System.currentTimeMillis();
            requests.computeIfAbsent(ip, k -> new ArrayList<>());
            List<Long> times = requests.get(ip);
            times.removeIf(t -> now - t > 60000);
            if (times.size() >= maxRequests) return Map.of("status", "rate limited");
            times.add(now);
            return null;
        };
    }
}
```
