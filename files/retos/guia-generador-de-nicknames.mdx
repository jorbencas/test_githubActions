# 🎯 Desafío: Generador de Nicknames

### 📝 Descripción del Reto
Genera un nickname a partir de un nombre completo tomando las primeras letras de cada palabra. Ejemplo: "Juan Carlos García" → "JCG". Práctica de split de cadenas, filtrado y formateo de salida.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Split + map | Separar palabras, tomar primera letra de cada una | O(n) |
| Bucle | Recorrer caracteres, detectar inicio de palabras | O(n) |
| Regex | `r'\b(\w)'` para capturar primera letra de cada palabra | O(n) |

### 🌍 Dónde se usa
- **Redes sociales**: generar usernames a partir de nombres reales
- **Sistemas corporativos**: crear identificadores de empleado
- **Juegos**: generar tags cortos para jugadores
- **Bases de datos**: crear códigos abreviados de entidades

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Separar el nombre en palabras, tomar la primera letra de cada una y unirlas. **Ejemplo:** "Juan Carlos García" → ["Juan", "Carlos", "García"] → ["J", "C", "G"] → "JCG".

### ⚙️ Paso 2: Implementación
Usar `split(' ')` para separar, `map` o list comprehension para tomar la primera letra, `join` para unir.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n)
**Complejidad espacial:** O(n)

```python
def generar_nickname(nombre):
    return ''.join(palabra[0].upper() for palabra in nombre.split())

print(generar_nickname('Juan Carlos García'))  # JCG
print(generar_nickname('Ana María'))            # AM
print(generar_nickname('Pedro'))                # P
print(generar_nickname('maría jose torres'))    # MJT
```

```javascript
function generarNickname(nombre) {
  return nombre.split(' ').map(p => p[0].toUpperCase()).join('');
}
console.log(generarNickname('Juan Carlos García'));  // JCG
console.log(generarNickname('Ana María'));            // AM
console.log(generarNickname('Pedro'));                // P
console.log(generarNickname('maría jose torres'));    // MJT
```

```java
public class GeneradorNicknames {
    public static String generarNickname(String nombre) {
        StringBuilder sb = new StringBuilder();
        for (String palabra : nombre.split(" ")) {
            sb.append(Character.toUpperCase(palabra.charAt(0)));
        }
        return sb.toString();
    }
    public static void main(String[] args) {
        System.out.println(generarNickname("Juan Carlos García")); // JCG
        System.out.println(generarNickname("Ana María"));           // AM
        System.out.println(generarNickname("Pedro"));               // P
        System.out.println(generarNickname("maría jose torres"));   // MJT
    }
}
```
