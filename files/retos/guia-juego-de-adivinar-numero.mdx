# 🎯 Desafío: Juego de Adivinar Número

### 📝 Descripción del Reto
Implementa un juego donde un número secreto (1-100) debe ser adivinado. En cada intento el jugador recibe pista: "demasiado alto", "demasiado bajo" o "¡correcto!". El juego termina cuando acierta o se queda sin intentos (máximo 10).

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad |
|---------|-------------|-------------|
| Bucle con contador | while con max_intentos, input del usuario | O(max_intentos) |
| Recursivo | Llamada recursiva con estado actualizado | O(max_intentos) pila |
| Búsqueda binaria | Estrategia óptima del jugador: siempre probar el medio | O(log n) intentos |

### 🌍 Dónde se usa
- **Juegos digitales**: mecánicas de adivinanza y sorteo
- **Educación**: enseñar lógica y estrategia a niños
- **Sorteos**: selección aleatoria de ganadores
- **Testing**: generar datos aleatorios para pruebas

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Generar número secreto aleatorio (1-100). Bucle hasta 10 intentos: leer input, comparar, dar pista. **Edge cases:** número fuera de rango, no numérico.

### ⚙️ Paso 2: Implementación
Usar `random.randint(1, 100)` para el número. Bucle while con contador. Comparar y guiar al jugador.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(max_intentos)
**Complejidad espacial:** O(1)

```python
import random

def juego_adivinar():
    secreto = random.randint(1, 100)
    intentos = 10
    for i in range(intentos):
        intento = int(input(f"Intento {i+1}/{intentos} - Tu número: "))
        if intento == secreto:
            return f"¡Correcto en {i+1} intentos!"
        elif intento < secreto:
            print("Demasiado bajo")
        else:
            print("Demasiado alto")
    return f"Sin intentos. El número era {secreto}"
```
