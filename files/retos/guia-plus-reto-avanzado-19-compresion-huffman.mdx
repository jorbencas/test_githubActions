# 🎯 Desafío: Reto Avanzado 19: Compresión Huffman

### 📝 Descripción del Reto
Implementa el algoritmo de compresión de Huffman:
1. **Contar frecuencias**: analizar el texto y contar apariciones de cada carácter
2. **Construir árbol**: crear un árbol binario donde las hojas son caracteres y los nodos internos son frecuencias combinadas
3. **Asignar códigos**: recorrer el árbol (izquierda=0, derecha=1) para generar códigos binarios
4. **Comprimir**: reemplazar cada carácter por su código Huffman
5. **Descomprimir**: recorrer el árbol desde la raíz con los bits para reconstruir el texto

**¿Por qué importa?** Huffman es la base de compresión en ZIP, gzip, JPEG y MP3. Asigna códigos más cortos a caracteres más frecuentes, logrando compresión sin pérdida.

**Habilidades que practica:** Árboles binarios, colas de prioridad (heap), codificación, compresión.

### 📊 Posibles enfoques

| Enfoque | Descripción | Complejidad Temporal | Complejidad Espacial |
|---------|-------------|---------------------|---------------------|
| Heap + merging | Heap de nodos, fusionar los dos menores | O(n log n) | O(n) |
| Frecuencias + greedy | Construir árbol greedymente | O(n log n) | O(n) |
| Diccionario de códigos | Generar tabla de códigos desde el árbol | O(n) compresión | O(n) |

### 🌍 Dónde se usa
1. **ZIP/gzip**: compresión de archivos usa Huffman como paso intermedio
2. **JPEG**: códec de imagen usa Huffman para codificar datos transformados
3. **MP3**: compresión de audio con tablas Huffman
4. **Transmisión**: optimizar ancho de banda enviando datos comprimidos

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Huffman asigna códigos más cortos a caracteres más frecuentes. Se construye un árbol binario donde las hojas son caracteres con su frecuencia, y los caminos izquierda=0, derecha=1 forman el código. **Ejemplo concreto:** 'aaabbc' → frecuencias: a:3, b:2, c:1 → árbol con a='0', b='11', c='10' → comprimido: '000111110'. **Edge cases:** texto con un solo carácter, caracteres con misma frecuencia, texto vacío.

### ⚙️ Paso 2: Implementación
**Implementación:** 1) Contar frecuencias con Counter/diccionario. 2) Construir cola de prioridad con nodos. 3) Fusionar los dos de menor frecuencia hasta que quede uno (el árbol). 4) Recorrer el árbol generando códigos. 5) Codificar el texto. 6) Decodificar recorriendo el árbol.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n log n) para construir el árbol  
**Complejidad espacial:** O(n)

```python
import heapq
from collections import Counter

class NodoHuffman:
    def __init__(self, char, freq):
        self.char = char
        self.freq = freq
        self.izq = None
        self.der = None
    def __lt__(self, other):
        return self.freq < other.freq

def comprimir_huffman(texto):
    if not texto:
        return "", {}
    freq = Counter(texto)
    pq = [NodoHuffman(c, f) for c, f in freq.items()]
    heapq.heapify(pq)
    while len(pq) > 1:
        izq = heapq.heappop(pq)
        der = heapq.heappop(pq)
        nodo = NodoHuffman(None, izq.freq + der.freq)
        nodo.izq = izq
        nodo.der = der
        heapq.heappush(pq, nodo)
    raiz = pq[0]
    codigos = {}
    def _generar(nodo, codigo=""):
        if nodo is None: return
        if nodo.char is not None:
            codigos[nodo.char] = codigo or "0"
            return
        _generar(nodo.izq, codigo + "0")
        _generar(nodo.der, codigo + "1")
    _generar(raiz)
    comprimido = "".join(codigos[c] for c in texto)
    return comprimido, codigos

def descomprimir_huffman(comprimido, codigos):
    if not comprimido:
        return ""
    invertido = {v: k for k, v in codigos.items()}
    resultado = []
    actual = ""
    for bit in comprimido:
        actual += bit
        if actual in invertido:
            resultado.append(invertido[actual])
            actual = ""
    return "".join(resultado)
```

```javascript
class NodoHuffman {
  constructor(char, freq) {
    this.char = char;
    this.freq = freq;
    this.izq = null;
    this.der = null;
  }
}

function comprimirHuffman(texto) {
  if (!texto) return { comprimido: "", codigos: {} };
  const freq = {};
  for (const c of texto) freq[c] = (freq[c] || 0) + 1;
  let pq = Object.entries(freq).map(([c, f]) => new NodoHuffman(c, f));
  pq.sort((a, b) => a.freq - b.freq);
  while (pq.length > 1) {
    const izq = pq.shift();
    const der = pq.shift();
    const nodo = new NodoHuffman(null, izq.freq + der.freq);
    nodo.izq = izq;
    nodo.der = der;
    pq.push(nodo);
    pq.sort((a, b) => a.freq - b.freq);
  }
  const codigos = {};
  function generar(nodo, codigo = "") {
    if (!nodo) return;
    if (nodo.char !== null) { codigos[nodo.char] = codigo || "0"; return; }
    generar(nodo.izq, codigo + "0");
    generar(nodo.der, codigo + "1");
  }
  generar(pq[0]);
  const comprimido = texto.split("").map(c => codigos[c]).join("");
  return { comprimido, codigos };
}

function descomprimirHuffman(comprimido, codigos) {
  if (!comprimido) return "";
  const invertido = {};
  for (const [k, v] of Object.entries(codigos)) invertido[v] = k;
  let resultado = "", actual = "";
  for (const bit of comprimido) {
    actual += bit;
    if (invertido[actual]) { resultado += invertido[actual]; actual = ""; }
  }
  return resultado;
}
```

```java
import java.util.*;

public class Huffman {
    static class Nodo implements Comparable<Nodo> {
        Character car; Integer freq;
        Nodo izq, der;
        Nodo(Character c, Integer f) { car = c; freq = f; }
        public int compareTo(Nodo o) { return this.freq - o.freq; }
    }

    public static Map<Character, String> comprimir(String texto) {
        Map<Character, Integer> freq = new HashMap<>();
        for (char c : texto.toCharArray()) freq.merge(c, 1, Integer::sum);
        PriorityQueue<Nodo> pq = new PriorityQueue<>();
        for (var e : freq.entrySet()) pq.add(new Nodo(e.getKey(), e.getValue()));
        while (pq.size() > 1) {
            Nodo izq = pq.poll(), der = pq.poll();
            Nodo nodo = new Nodo(null, izq.freq + der.freq);
            nodo.izq = izq; nodo.der = der;
            pq.add(nodo);
        }
        Map<Character, String> codigos = new HashMap<>();
        generarCodigos(pq.peek(), "", codigos);
        return codigos;
    }

    private static void generarCodigos(Nodo nodo, String codigo, Map<Character, String> codigos) {
        if (nodo == null) return;
        if (nodo.car != null) { codigos.put(nodo.car, codigo.isEmpty() ? "0" : codigo); return; }
        generarCodigos(nodo.izq, codigo + "0", codigos);
        generarCodigos(nodo.der, codigo + "1", codigos);
    }
}
```

```typescript
  }
}

function comprimirHuffman(texto: string): { comprimido: string; codigos: Record<string, string> } {
  if (!texto) return { comprimido: "", codigos: {} };

  for (const c of texto) freq[c] = (freq[c] || 0) + 1;

    const izq = pq.shift()!;
    const der = pq.shift()!;
    const nodo = new NodoHuffman(null, izq.freq + der.freq);
    nodo.izq = izq; nodo.der = der;
    pq.push(nodo);
    pq.sort((a, b) => a.freq - b.freq);
  }
  const codigos: Record<string, string> = {};
  function generar(nodo: NodoHuffman | null, codigo: string = ""): void {

}
```
